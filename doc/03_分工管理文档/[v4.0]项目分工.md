### 2. 缺少的关键功能 (Gap Analysis)

根据 v4.0 版本测试结果，以下核心功能缺失导致系统可用性受限：

1.  **查询类功能全线缺失 (High Criticality)**：
    *   **学生无法查看课表**：用户无法确认已选课程。
    *   **学生无法查看成绩**：成绩录入后，学生端无反馈。
    *   **教师无法查看授课名单**：教师必须盲猜学生 ID 才能打分。

2.  **细粒度管理功能缺失**：
    *   教学秘书无法修改已创建课程的属性（如变更教师、调整时间）。

3.  **安全性与健壮性不足**：
    *   **无身份鉴权**：Controller 层直接接受 ID 参数，未校验当前会话身份。
    *   **无密码验证**：登录仅验证 ID 存在性。

### 3. [v5.0] 优化与开发计划

v5.0 目标：**完善查询视图，增强系统健壮性，实现“真正可用”。**

#### **3.1 功能补全 (High Priority)**

*   **学生 - 查看课表 (`View Schedule`)**:
    *   **后端**: 在 `StudentProxy` 中实现 `findSchedule(studentId)`，执行 JOIN 查询获取课程详情（时间、地点、教师）。
    *   **UI**: 格式化输出课程表，按星期/节次排序。

*   **学生 - 查看成绩 (`View Grades`)**:
    *   **后端**: 在 `EnrollmentProxy` 中实现 `findGrades(studentId)`，返回 `Course + Score` 列表。
    *   **UI**: 列表展示课程名、学分、成绩。

*   **教师 - 查看授课名单 (`View Roster`)**:
    *   **后端**: 在 `CourseProxy` 中实现 `findStudentsByCourse(courseId)`。
    *   **UI**: 展示学生 ID、姓名、当前成绩状态。

#### **3.2 架构与逻辑优化 (Medium Priority)**

*   **引入会话管理 (Session Context)**:
    *   在 `SystemController` 中维护 `CurrentUser` 上下文。
    *   **鉴权**: 确保学生只能操作自己的选课，教师只能录入自己课程的成绩。

*   **登录认证增强**:
    *   启用数据库 `users` 表中的 `password` 字段进行校验。

#### **3.3 仓库类封装 (Architecture Refinement)**

*   **Repository Pattern**:
    *   将 `Proxy` 升级为 `Repository`，增加 `findAllAvailable()`, `findByCriteria()` 等高级查询接口，支持分页和筛选。





# [v5.0] 项目分工规划

## 1. 项目当前实现状态分析 (Status Report)

v4.0 版本成功建立了 4 层架构的骨架，但系统处于“盲操作”状态，用户体验极差。

- **✅ 已达成成就 (What's Done)**
  - **架构合规**：完全实现了 Presentation -> Application -> Domain -> Infrastructure 的单向依赖，C++23 Modules 构建系统稳定。
  - **核心写操作**：学生选课/退课、教师录入成绩、教学秘书创建课程的**写入链路**已打通项目分工.md]。s
  - **数据持久化**：`DBAdapter` 与 `Proxy` 配合良好，数据能正确存入 PostgreSQL。
- **❌ 严重缺陷 (Critical Gaps)**
  - **“盲盒”体验**：CLI 中大量功能显示“功能开发中”。学生选了课看不到课表，教师打了分看不到名单项目分工.md]。
  - **安全裸奔**：`UserInterface` 直接通过 `cin >> user_id` 登录，无密码校验；Controller 层未校验操作者身份（例如：学生A可以输入学生B的ID进行退课）。
  - **复杂查询缺失**：目前的 Proxy 仅支持简单的 CRUD，缺乏多表关联查询 (JOIN) 能力。
- **🚀 v5.0 阶段目标**
  - **全视图可见**：实现“查看课表”、“查看成绩”、“查看授课名单”三大查询视图。
  - **会话管理**：引入 `SessionContext`，实现登录鉴权与操作权限控制。
