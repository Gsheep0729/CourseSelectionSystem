### 2. 领域层核心算法 (Domain Core)

**目标**: 实现时间冲突检测逻辑。这是业务逻辑中最复杂的部分。

- **参考文档**: 《需求规格说明书》 2.2.1 章节
- **关键规则**: 同一 weekday 且 timeslot 重叠即为冲突。

#### 2.1 定义时间槽 (`Timeslot`)

- **文件**: `src/CourseSelectionSystem/domain/dom.timeslot.cppm`
- **要求**: 必须实现 `overlaps` 方法。

```c++
export module course_system:domain.timeslot;
import std;

export struct Timeslot {
    int weekday;  // 1-5 (Mon-Fri)
    int slot_id;  // 1-6 (1=1-2节, 2=3-4节, ...)

    // 核心算法：检查两个时间槽是否冲突
    bool overlaps(const Timeslot& other) const {
        // 规则：如果星期相同 且 节次相同，则冲突
        return (weekday == other.weekday) && (slot_id == other.slot_id);
    }

    std::string toString() const {
        return std::format("Day {} Slot {}", weekday, slot_id);
    }
};
```
