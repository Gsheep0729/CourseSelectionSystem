  1. 核心会话与认证 (Auth)

  现在的登录逻辑已经接入数据库 users 表。在 UI 层调用登录后，控制器会自动维护“当前用户”会话，后续查询无需手动传 ID。

   - 接口：bool login(string id, string password)
   - 说明：
     - 返回 true 表示登录成功，系统会记录当前用户的角色和 ID。
     - 登录失败请提示“账号或密码错误”。

  2. 学生端功能：查看课表 (View Schedule)

  学生登录后，点击“查看课表”应调用此接口。后端已通过 JOIN 自动关联了课程名、教师和时间。

   - 接口：std::vector<Course> getMySchedule()
   - 返回数据说明：返回 Course 对象列表。常用方法：
     - c.getId(): 课程编号
     - c.getName(): 课程名称
     - c.getTeacherName(): 授课教师
     - c.getTimeslot().toString(): 上课时间字符串 (如 "Wed Slot 2")
   - UI 对接示例：

  ```
  // 在 showStudentMenu 的 Case 3 调用
  auto schedule = m_controller->getMySchedule();
  if (schedule.empty()) {
      std::print("您当前尚未选修任何课程。\n");
  } else {
      std::print("{:<12} | {:<20} | {:<12} | {:<15}\n", "课程ID", "课程名称", "教师", "时间");
      for (const auto& c : schedule) {
          std::print("{:<12} | {:<20} | {:<12} | {:<15}\n",
                     c.getId(), c.getName(), c.getTeacherName(), c.getTimeslot().toString());
      }
  }
  ```

  3. 教师端功能：查看授课名单 (View Roster)

  教师需要输入其名下的课程 ID 来获取选课学生名单及成绩。

   - 接口：std::vector<infra::CourseStudentDTO> getCourseStudentList(string courseId)
   - 数据结构 `CourseStudentDTO` 成员：
     - id: 学生学号 (string)
     - name: 学生姓名 (string)
     - score: 成绩 (int)。注意：如果值为 -1，表示该生尚未录入成绩。
   - UI 对接示例：

```
// 在 showTeacherMenu 的 Case 1 调用
std::string cid = get_user_input("请输入课程ID: ");
auto roster = m_controller->getCourseStudentList(cid);

if (roster.empty()) {
    std::print("未找到该课程或该课程暂无学生报名。\n");
} else {
    std::print("\n--- 授课名单 [{}] ---\n", cid);
    std::print("{:<15} | {:<15} | {:<10}\n", "学号", "姓名", "成绩");
    for (const auto& s : roster) {
        std::string scoreDisplay = (s.score == -1) ? "N/A" : std::to_string(s.score);
        std::print("{:<15} | {:<15} | {:<10}\n", s.id, s.name, scoreDisplay);
    }
}
```
