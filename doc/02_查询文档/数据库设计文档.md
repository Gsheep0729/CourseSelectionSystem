# 选课管理系统数据库设计文档

以下文档详细描述了 PostgreSQL 数据库的表结构设计及初始化默认数据。

## 1. 数据库配置概览

- **数据库名称**: `CourseSelectionSystem`
- **默认端口**: `5432`
- **默认管理员**: `postgres`
- **默认密码**: `123`
- **主机地址**: `127.0.0.1`

## 2. 数据库表结构设计

系统共包含四张核心数据表：用户表 (`users`)、学生表 (`student`)、课程表 (`course`)、选课记录表 (`enrollment`)。

### 2.1 用户表 (users)

用于存储系统所有角色的登录凭证及身份信息。

| **字段名**   | **数据类型** | **约束条件**                                        | **说明**                   |
| ------------ | ------------ | --------------------------------------------------- | -------------------------- |
| **user_id**  | VARCHAR(50)  | PRIMARY KEY                                         | 用户唯一标识（学号或工号） |
| **name**     | VARCHAR(50)  | NOT NULL                                            | 用户姓名                   |
| **password** | VARCHAR(50)  | DEFAULT '123'                                       | 登录密码                   |
| **role**     | VARCHAR(20)  | CHECK (role IN ('student', 'teacher', 'secretary')) | 角色类型                   |

### 2.2 课程表 (course)

存储课程的基础信息、授课教师及时间安排。

| **字段名**       | **数据类型** | **约束条件** | **说明**                   |
| ---------------- | ------------ | ------------ | -------------------------- |
| **id**           | VARCHAR(50)  | PRIMARY KEY  | 课程代码                   |
| **name**         | TEXT         | NOT NULL     | 课程名称                   |
| **capacity**     | INT          | DEFAULT 120  | 课程容量上限               |
| **enrolled**     | INT          | DEFAULT 0    | 当前已选人数               |
| **credit**       | REAL         | DEFAULT 0.0  | 学分                       |
| **teacher_id**   | TEXT         | -            | 授课教师工号               |
| **teacher_name** | TEXT         | -            | 授课教师姓名               |
| **weekday**      | INT          | -            | 上课星期 (1至7，0为网络课) |
| **timeslot**     | INT          | -            | 上课节次 (1至5)            |

### 2.3 学生表 (student)

存储学生的学籍信息，用于关联选课记录。

| **字段名** | **数据类型** | **约束条件** | **说明** |
| ---------- | ------------ | ------------ | -------- |
| **id**     | VARCHAR(50)  | PRIMARY KEY  | 学生学号 |
| **name**   | TEXT         | -            | 学生姓名 |

### 2.4 选课记录表 (enrollment)

存储学生与课程的关联关系及最终成绩。

| **字段名**     | **数据类型** | **约束条件**                        | **说明**               |
| -------------- | ------------ | ----------------------------------- | ---------------------- |
| **student_id** | VARCHAR(50)  | REFERENCES student(id)              | 外键，关联学生表       |
| **course_id**  | VARCHAR(50)  | REFERENCES course(id)               | 外键，关联课程表       |
| **score**      | INTEGER      | DEFAULT NULL                        | 考试成绩               |
| **PKEY**       | -            | PRIMARY KEY (student_id, course_id) | 联合主键，防止重复选课 |
